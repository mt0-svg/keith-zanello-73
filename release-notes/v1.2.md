Conjecture B of Keith and Zanello is false: at p = 73 exactly twenty odd t have a full set of even progressions, the largest being t = 203.

This is AI-generated research: the results, proofs and code were found and written by AI. Credit goes to all the humans whose work it builds on.

**Proved in Lean 4:** `KeithZanello.conjectureB_false` and `KeithZanello.theorem1`, with Mathlib and only the standard axioms, checked against `KZ73/Challenge.lean` by Comparator. **By computation:** Theorems 2 and 3 of the paper, by certificates that `paper/check.sh` reruns, partly redone by a second program (see the README).

Assets: the paper; `verification-v1.2.tar.gz`, the complete output of every check rerun for this release; and `keith-zanello-73-x86_64-unknown-linux-gnu.tar.gz`, the Lean build that Comparator checked for this release. `lake build :release` in a clone at v1.2, or `lake build` in a package that requires keith-zanello-73 at v1.2, downloads this build instead of compiling the package (on Linux x86_64, with Lean and Mathlib v4.34.1).
